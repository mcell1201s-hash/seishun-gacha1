# 青春ガチャ。

**部活は選べない。青春は選べる。**

スマートフォン縦画面を中心にした高校3年間の育成シミュレーションのプロトタイプです。野球部・吹奏楽部・美術部からランダムに所属が決まります。1周5〜8分を目標としていますが、現段階では短いテキスト中心のためプレイ時間は操作速度によります。

## 起動

ビルド・依存パッケージ・API・ログインは不要です。リポジトリのルートで以下を実行し、ブラウザで `http://localhost:8000` を開いてください。

```sh
python3 -m http.server 8000
```

ES Modulesを使用するため、HTMLを直接ファイルとして開かずHTTPサーバーを利用してください。GitHub Pagesでは Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選びます。PRをmainにマージした後で公開できます。サブディレクトリ配信にも対応する相対パスです。

## 今回の実装

入学ガチャ → 育成20回 → 引退・卒業エピローグ4回 → 卒業結果・アルバム。入学時に学校名、部活、基礎戦力（0〜200）、育成環境（0〜100）、校内競争（0〜200）、能力、成長適性を抽選します。環境と競争には基礎戦力との緩い相関と独立したばらつきがあり、学校の固定タイプはありません。適性は特定能力の成長1.1倍です。

| 学年 | ターン | 大会（育成行動後） |
| --- | --- | --- |
| 1年 | T1〜8 | T4、T8 |
| 2年 | T9〜16 | T12、T16 |
| 3年 | T17〜20 | T18、T20（最終大会・引退） |
| 引退後 | T21〜24 | エピローグのみ |

各ターンは **育成の基本効果 → 出会い・追加イベント → ケガ抽選 → 大会（該当時）→ 大会終了・疲労回復 → 次ターン・進級回復** の順。大会画面は追加行動を消費せず、大会を閉じると次のターンへ進みます。T9・17への進級時に疲労−25、大会終了時に−15。

6つの共通コマンドを用意。練習による能力成長には環境補正（0.8〜1.2倍）と適性補正を掛け、行動前の疲労60以上は0.8倍、80以上は0.6倍とし、最後に四捨五入します。成長の逓減はありません。能力は0〜200、疲労・連携・好感度は0〜100に制限します。練習以外の基本成長には環境・疲労補正は掛けません。

基本効果はケガやイベントが発生しても適用されます。追加イベントは全コマンド共通でプラス18%、マイナス12%（相互排他）。連携は発生確率に影響しません。練習のケガ確率は通常2%、疲労60以上8%、80以上18%で、疲労+8・精神−3です。

交流で35%の出会い抽選を行い、出会うとデートが解放されます。大会の勝敗・レギュラー判定・恋愛の詳細・追加トロフィーは次回実装です。現時点の大会は部活別の参加演出のみで、勝敗を捏造しません。

卒業時の能力、学校、部活、大会参加数、卒業トロフィーをlocalStorageに最大50件保存します。保存が無効な場合も遊べますが警告を表示します。育成途中の再開は未対応で、再読み込みするとタイトルに戻ります。端末・ブラウザ間の共有はありません。

## ファイル構成

- `js/config.js`：ゲームバランス用定数・部活データ
- `js/random.js`：乱数の集約（テスト用の乱数源を注入可能）
- `js/state.js`：状態初期化・保存
- `js/game.js`：画面遷移・育成・大会タイミング
- `js/view.js`：表示、`js/app.js`：入力と各モジュールの接続
- `style.css`：スマホ優先のレイアウト

## 検証

Node.js 22以降（推奨24）で、外部パッケージなしで実行できます。

```sh
node --test tests/game.test.mjs
```

20育成行動、6大会、進級、4エピローグ、疲労補正、出会い、保存・保存失敗などを検証します。
